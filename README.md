# Telco Customer Churn Analysis

Analysis of Telco customer churn using SQL and Power BI to identify key churn drivers by internet service, contract type, tenure, and charges.

## Tools Used
- SQL (MySQL)
- Power BI
- GitHub

## Project Structure
- sql/ - SQL queries for churn analysis
- powerbi/ - Interactive Power BI dashboard

## Key Insights
- Fiber optic customers churn more than DSL customers
- Month-to-month contract customers have the highest churn rate
- New customers (0-12 months tenure) churn the most
- Churned customers have higher average monthly charges

## Dashboard
Interactive dashboard showing churn rate, churn by service, contract, tenure and charges.
